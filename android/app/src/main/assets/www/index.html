  • 网易云：歌单链接或纯数字 id

  • 分隔符：TAB、竖线 |、-、多空格都行
  • 自动跳过表头/说明行；歌曲: 前缀、多歌手会自动规整

从截图里识别歌名和歌手
  • 支持「歌名一行 / 歌手一行」的列表截图，长截屏会自动分块识别
  • 识别结果会填到「文本」页，核对后再导入
  • 图片越清晰越准；糊图建议改用链接或文本导入
